# Triage Labels

| 技能角色 | 本專案狀態 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待評估 |
| `needs-info` | `needs-info` | 等待補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由 agent 執行 |
| `ready-for-human` | `ready-for-human` | 需要人工處理 |
| `wontfix` | `wontfix` | 不處理 |

本機工單如需狀態，在工單標題下使用 `Status:` 記錄對應字串。
