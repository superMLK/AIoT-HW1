# 全幅地圖與公開更新

觀測頁使用全幅地圖，摘要、特報、圖層採可收合浮動面板。行政區選擇只放預報頁，不觸發頁面跳轉。

手動更新不要求訪客輸入秘密。每個來源透過資料庫原子租約限制五分鐘一次，連失敗的請求也受限制；排程 GET 仍須 CRON_SECRET。重複請求回報快取／冷卻狀態，不顯示成同步失敗。來源白名單仍適用。

測站雨量以有限範圍的平滑色塊表示觀測分布，不將其宣稱為雷達降水或海上實測。濕度以測站色點表示。風向使用氣象學來向轉換成流向。

預報驗證只能使用事前保存的真實預報。代表站擴充須限制同一行政區、具逐時氣溫資料，並保存固定配對；不得用事後預報回填成事前預報。資料不足應說明缺少代表站、歷史預報或同期觀測。

風場新增經使用者同意的 NOAA GFS 官方 ERDDAP JSON，保存 0.5°、10 m 的 U/V 格點，不新增解析套件。雷達有獨立資料庫影像快取與每張 60 秒租約。代表站使用同區有效逐時站中 station_id 最小者作固定初選；保留既有人工配對，這不是地形適宜性評估。
